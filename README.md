# My Builder Page
A simple website used to showcase and give people a basic rundown of me.

## Description
This is my builder webpage for Pixl's "Raise Your Build Page" trial. The website acts as a sort of introduction to 
me and a showcase to use later on. This project was built using HTML, CSS, and Javascript and is hosted using GitHub Pages. To access the site, go to https://jtylerengineering.github.io/builderpage/.
